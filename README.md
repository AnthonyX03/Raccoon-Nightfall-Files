# Raccoon Nightfall Files — v1.5

## Cambios
- Baúl rediseñado con selección múltiple, inspirado en el flujo de Combinar.
- Selecciona uno o varios objetos del inventario y pulsa **Guardar seleccionados**.
- Selecciona una o varias categorías del baúl y pulsa **Sacar seleccionados**.
- Las armas se conservan correctamente al guardarlas; si estaban equipadas se desequipan.
- La munición se mueve como pila y respeta los límites del inventario.
- Los documentos permanecen separados del inventario y del baúl.
- Se mantiene la corrección del lector de documentos para que no reabra el último documento.
- Se conserva el sistema de misiones por exploración y la corrección de audio.

## Uso
1. En una zona segura, abre **Inventario**.
2. Toca/clica los objetos que quieras guardar.
3. Pulsa **Guardar seleccionados**.
4. En la pestaña **Baúl**, selecciona lo que quieras recuperar.
5. Pulsa **Sacar seleccionados**.
